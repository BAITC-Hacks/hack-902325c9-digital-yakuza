# Workflow: агент → план → факты → ИИ-объяснение → отчёт

```bash
cd beeline_agent
pip install -r requirements.txt openai
cp .env.example .env            # вписать OPENAI_API_KEY (опционально _2, _3); .env не коммитится
python workflow.py              # seed 42 — тот же план, что make_submission.py
python workflow.py --no-llm     # без модели: шаблонное объяснение
```

Ожидаемый вывод:
```
план: 5 кампаний, net (мок) 4,777,157
объяснение: llm
модель gpt-5.6-luna, токены in/out …, задержка … с, ключ №1, стоимость …
файлы: outputs/submission.csv, report.json, explanation.md
```

## Выходные файлы (`outputs/`, не в git)
| Файл | Что внутри |
|---|---|
| `submission.csv` | план агента; байт в байт совпадает с `make_submission.py` при том же seed |
| `report.json` | план, метрики (мок-подсчёт организаторов), факты с id, объяснение (сырое со ссылками и отрисованное), расход модели, журнал решений агента — формат для backend |
| `explanation.md` | объяснение для аналитика, с пометкой источника: модель или шаблон |

## Как устроено
1. **Агент** (`agent.py`, статистика) выбирает пилоты и план. ИИ в этом не участвует.
2. **Факты** считает код: `M` — итоги, `C1…` — кампании, `P1…` — пилоты, `W1` — сводка неподтверждённых проб; предупреждения — правила кода.
3. **Один вызов модели** (`OPENAI_MODEL_FAST`) объясняет весь план. Модель пишет текст со ссылками `{C1.contacts}`, **числа подставляет код**. Ответ с цифрами вне ссылок, с неизвестными id или не по JSON-схеме отклоняется.
4. **Запасной путь**: нет ключа, таймаут, ошибка API или отклонённый ответ → шаблонное объяснение; в отчёте `explanation.source = "template"` и причина.
5. **ИИ не меняет план и CSV** — объяснение строится после плана.

## Настройки (`.env`, окружение важнее)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `OPENAI_API_KEY`, `_2`, `_3` | — | ключи; следующий берётся только при 401/403/исчерпанной квоте |
| `OPENAI_MODEL_FAST` | `gpt-5.6-luna` | модель объяснения |
| `AGENT_LLM_REASONING_EFFORT` | `low` | усилие рассуждения |
| `AGENT_LLM_TIMEOUT_SECONDS` | `30` | таймаут вызова |
| `AGENT_LLM_MAX_OUTPUT_TOKENS` | `2000` | лимит ответа |
| `AGENT_LLM_MAX_ATTEMPTS` | `2` | попыток на ключ (сеть, 429) |
| `AGENT_LLM_PRICE_INPUT_PER_1M`, `_OUTPUT_PER_1M` | не заданы | цены в USD за 1 млн токенов — для оценки стоимости |
| `AGENT_LLM_RUN_BUDGET_USD` | — | предупреждение, если оценка стоимости выше |

Без цен стоимость в отчёте — `null` с пометкой; токены и задержка пишутся всегда.
